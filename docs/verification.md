# 動作確認
- Windows + Shift + S → Ctrl + Vで画像表示と英語OCR。
- 画像がないクリップボードから貼り付けると案内が表示される。
- PNG/JPEGを開く、ドラッグ＆ドロップして読み取る。
- 読み取り後に自動で日本語訳。英文編集後の再翻訳。
- 翻訳中は動き続けるバーと経過秒数が出て、訳が少しずつ表示される。
- 「中止 (Esc)」ボタンと Esc キーで翻訳が止まり、途中までの訳が残る。中止の後も続けて翻訳できる。
- Ollama が起動していない、モデルが無い場合の案内。
- 次の画像読み込み時に前の英文・訳がクリアされる。
- 設定を保存して再起動すると、モデル・アドレス・共通の単語辞書・ゲームの一覧・選んでいるゲーム・文字の大きさが復元される。
- ゲームを切り替えると、そのゲームの単語辞書で訳が変わる。
- 訳が見出し・箇条書き・太字で表示され、A− / A＋ で文字の大きさが変わる。コピーした文章に Markdown の記号が残らない。
- Ollama を終了した状態で翻訳すると、自動で起動して翻訳できる。アプリを閉じると、アプリが起動した Ollama は止まる。
- 実ゲーム画像の装飾文字・小さい文字で精度を評価。
