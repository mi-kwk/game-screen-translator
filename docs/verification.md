# 動作確認
- Windows + Shift + S → Ctrl + Vで画像表示と英語OCR。
- 画像がないクリップボードから貼り付けると案内が表示される。
- PNG/JPEGを開く、ドラッグ＆ドロップして読み取る。
- APIキー未設定でOCRを使える。翻訳時に設定案内。
- 有効なDeepLキーで日本語訳。英文編集後の再翻訳。
- 不正キー、Free/Pro違い、接続失敗、上限到達の案内。
- 次の画像読み込み時に前の英文・訳がクリアされる。
- 設定を保存して再起動するとキーとプランが復元される。
- 実ゲーム画像の装飾文字・小さい文字で精度を評価。

実際のAPI翻訳はユーザーのAPIキーが必要。ソースにキーを埋め込まない。
