# 動作確認
- Windows + Shift + S → Ctrl + Vで画像表示と英語OCR。
- 画像がないクリップボードから貼り付けると案内が表示される。
- PNG/JPEGを開く、ドラッグ＆ドロップして読み取る。
- 読み取り後に自動で日本語訳。英文編集後の再翻訳。
- Ollama が起動していない、モデルが無い場合の案内。
- 次の画像読み込み時に前の英文・訳がクリアされる。
- 設定を保存して再起動すると、モデル・アドレス・ゲーム名・単語辞書が復元される。
- 実ゲーム画像の装飾文字・小さい文字で精度を評価。

開発用 PC: RTX 3060 12GB / メモリ 32GB / gemma3:12b / Ollama 0.40.15。
- Releaseビルド: 警告0、エラー0。win-x64自己完結型publish: 成功。
- 自動検証(tests/Smoke): 画面初期化、実OCR、OCRの後処理(O/0)、設定の保存と読み込み、Ollama への要求と応答・モデルが無い・Ollama に接続できない(モック)がすべて成功。
- 実 Ollama: アプリの OCR と翻訳の処理で、Active Matter のニュース画像を翻訳できた(約 8 秒)。存在しないモデル、起動していないアドレスで、それぞれの案内が出ることを確認。
- 画面: 設定欄を開いた状態のメイン画面を画像にして、レイアウトの崩れがないことを確認。
- 翻訳品質(Active Matter の Steam ニュース・変更履歴 7 枚):
  - Windows OCR は英文をほぼ正確に読み取れる(1 枚 0.1〜0.3 秒)。0 と O の取り違え、UI の断片、ロシア語の誤認識はある。
  - 単語辞書とゲーム名なし: 読める訳だが、plant → 植物、extraction → エキザクト、raid の訳の揺れなど、用語の誤訳があった。
  - 単語辞書とゲーム名あり: 用語の誤訳はほぼ解消。barges → バージョン、round → マガジンなど、文の読み違いが少し残る。
  - 時間: 最初の 1 回は読み込みで約 35 秒。以降は短い文で約 3 秒、長いページで 20〜30 秒。
  - 画像を直接渡す方式: 英語のまま返す・内容を作り変えることがあり、採用しない。
- 未確認: アプリを使う PC(RTX 3090 24GB)での gemma3:27b の品質と速度、手動の貼り付け操作。
