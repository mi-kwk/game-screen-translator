# 設計
- 対象: Windows 11、win-x64。
- 入力: クリップボード画像、画像ファイル、ドラッグ＆ドロップ。
- OCR: Windows.Media.Ocr、en-US、行単位で抽出。上限を超える画像は縮小。数字に挟まれた英字の O は 0 に直す(例: 0.4.O.192 → 0.4.0.192)。
- 画面のまとまり: OCR の行の位置から、画面上のまとまり(段組み・横に並んだ欄など)に分ける。すぐ下にあり(文字の高さの 2.5 倍以内)、左端がほぼ揃い(4 倍以内)、横の範囲が重なる行を同じまとまりとする。まとまりの間には「---」の行を入れ、訳でも区切り線として残す。ボタン名やタブなど 1〜2 行の短いまとまりは、続けて並ぶものをひとまとめにする。
- 英語以外の文章: 英語の OCR はロシア語などを崩れた文字列(例: neAb1 rpß3Hb1X)として読むため、英語らしい単語の割合と the / and などの多さで判断し、英語以外のまとまりは翻訳から外して案内する。英単語を含まない短い行(数字だけの日付、崩れた日本語のボタン名など)は捨てる。
- 書き写しの除去: モデルが原文の英文を書き写した段落(英字が大半で 8 語以上、単語の 6 割以上が原文にある)は、翻訳の完了時に取り除く。
- 翻訳: Ollama のローカル LLM(初期値 gemma3:12b)、ENからJA。`/api/chat` を stream ありで呼び、届いた分から訳の欄に追記する。temperature 0.2、num_ctx 8192。訳が届き始めるまでは3分でタイムアウト。
- 処理中の表示: 所要時間が分からないため、進み具合ではなく動き続けるバー(不確定のプログレスバー)と経過秒数を出す。訳が届くまでは「モデルを準備しています」、届き始めたら「翻訳しています」。
- 中止: 翻訳中だけ「中止 (Esc)」ボタンを出す。Esc キーでも止められる。途中までの訳は残す。
- 翻訳の指示: ゲームの文章向けの基本の指示に、Markdown で出力する指示、選んだゲームの名前と説明、共通の単語辞書、選んだゲームの単語辞書を足す。同じ語はゲームの単語辞書を優先させる。
- 訳の表示: Markdown を FlowDocument に変えて表示する(見出し・箇条書き・番号付きリスト・引用・区切り線・太字・斜体・コード)。「？」で終わる行は Q&A の質問として青い太字にする(モデルが太字にしなくても目立つように)。文字の大きさは 12〜32 で変えられ、設定に保存する。少しずつ届く間は 120ms ごとに表示を作り直す。
- コピー: Markdown の記号を外した文章をコピーする(箇条書きは「・」)。
- Ollama の自動起動: アドレスがこの PC(localhost / 127.0.0.1)のとき、アプリの起動時と翻訳の前に Ollama が動いているか確かめ、止まっていれば `ollama serve` を画面なしで起動して最大 30 秒待つ。11434 以外のポートは OLLAMA_HOST で渡す。アプリが起動した Ollama だけを、アプリの終了時に止める。設定でオフにできる。
- ゲームの切り替え: メイン画面右上の一覧で選ぶ。「(ゲームを選ばない)」なら共通の単語辞書だけを使う。
- UI: 画像、編集可能な英文、日本語訳。処理中は並行実行を防止。設定は別の画面(設定…)。
- 設定: Ollama のアドレス・モデル・自動起動・共通の単語辞書・ゲームの一覧(名前・説明・単語辞書)・選んでいるゲーム・文字の大きさを LocalAppData/GameScreenTranslator/settings.json に保存。秘密の情報は無いので暗号化しない。以前の形式(ゲーム名と単語辞書が 1 つ)は、ゲーム 1 件として読み込む。
- 画面の見張り(自動で訳す小窓):
  - 範囲: 画面全体を薄暗くしてドラッグで選ぶ(物理ピクセルで保存)。選ぶ間はメイン画面をしまう。
  - 撮影: 2 秒ごと(1〜10 秒で変更可)に GDI の BitBlt で範囲をコピーする。ゲームには触れない。小窓が範囲に重なるときは、自分の訳を読まないよう撮る瞬間だけ透明にする。
  - 変化の判定: 3 ピクセルおきに明るさを比べ、0.4% を超えて変われば「変化あり」。変化の直後は 1 回待ってから読む(文字が出きるのを待つ)。動き続ける画面でも 2 回目には読む。変化がなければ読み取りも翻訳もしない。
  - 同じ英文の判定: 単語の重なりが 9 割以上なら訳し直さない(OCR の小さな読み違い対策)。
  - 翻訳: 見張るときのモデル(初期値 gemma3:12b)で訳す。翻訳中に新しい英文が出たら、古い翻訳を止めて新しいほうを訳す。
  - 小窓: 常に手前・半透明(濃さ 40〜100%)・クリックはゲームに通す。Ctrl + Shift を押している間だけ移動と大きさの変更ができる。上端に状態(見張り中・読み取り中・翻訳中と経過秒数)を出す。位置と大きさは保存する。
  - ON / OFF: ホットキー Ctrl + Shift + T、メイン画面右上のスイッチ、小窓の状態表示。OFF にすると撮影を止め、Ollama にモデルを外させて GPU のメモリをすぐ空ける(keep_alive: 0)。
  - DPI: 選んだ範囲と撮る範囲を一致させるため、アプリをモニターごとの DPI に対応させる(app.manifest の PerMonitorV2)。
- 翻訳履歴:
  - 保存: 翻訳が終わったら(貼り付け・見張りの両方)、英文・訳・日時・ゲーム名・どこから(貼り付け / 見張り)を PC の中の SQLite(LocalAppData/GameScreenTranslator/history.db)に保存する。画像は保存しない。同じゲームで同じ英文(空白と大文字小文字の違いは無視)は 1 件にまとめて上書きする。「翻訳を履歴に保存する」でオフにできる。
  - 意味の数値: 訳を段落ごとの小さなまとまり(目安 150 文字。見出しは次の段落とつなぎ、長い段落は文で分ける)に分け、Ollama の埋め込み用モデル(初期値 bge-m3、多言語)で埋め込みを作ってまとまりごとに保存する。保存の後に裏で順番に作る。長い文書を 1 つの数値にすると意味がぼやけるため、まとまりに分けた(実際の訳で比べて決めた)。
  - 検索: 検索の言葉も埋め込みに変え、履歴ごとに「いちばん近いまとまり」のコサイン類似度で並べる。言葉が英文か訳にそのまま含まれる履歴は先に並べる(固有名詞を確実に探すため)。類似度 0.5 未満で言葉も含まれない履歴は出さない。埋め込み用モデルが使えないときは、言葉そのままで探す。
  - 画面: 履歴…(検索欄・ゲームで絞り込み・結果の一覧・見つかった部分・訳と英文の全文・コピー・1 件削除・全部削除・保存のオンオフ)。
- 外部への通信: なし(Ollama は同じ PC で動かす)。履歴も PC の外に出さない。
- ゲームへの介入は対象外。

## 決定の経緯
### 2026-11-08 翻訳履歴の保存と、意味で探す機能を追加
- これまで「翻訳履歴は保存しない」としていたが、ローカル AI の「自分のデータを PC の中にためて使える」強みを生かすため、PC の中だけに保存して意味で探せるようにした。
- 決めたこと(利用者と合意): 保存するのは英文・訳・日時・ゲーム名、見張りの訳も保存(同じ英文はまとめる)、埋め込み用モデルは多言語の bge-m3、意味と言葉そのままの組み合わせで探す、保存先は SQLite、1 件削除・全部削除・保存しないスイッチ。
- 文書全体を 1 つの埋め込みにすると、関係のない文書が上位に来た(例:「敵が強くなる話」で Icarus Offices が 1 位)。段落ごとのまとまりに分けると、「シェルターの家具」→ 椅子やソファの Q&A(0.59)、「照準のブレ」→ スコープの修正(0.56)のように、言葉が違っても見つかるようになった。

### 2026-11-08 画面の見張り(常時監視)を追加
- これまで「常時監視は対象外」としていたが、ローカル AI は何回使っても無料で、画面を外に送らないという強みを生かせるため追加した。
- ゲームには一切手を出さず、表示されている画面をコピーして読むだけにする。
- ゲームと GPU を分け合うため、見張るときのモデルは通常の翻訳と別に設定できるようにし、初期値は gemma3:12b(約 8GB)にした。OFF で GPU のメモリをすぐ空ける。
- 決めたこと(利用者と合意): 範囲はドラッグで選ぶ、間隔 2 秒、小窓は常に手前・半透明・クリックを通す、訳は最新だけ、ON / OFF はホットキー + スイッチ + 小窓の状態表示。

### 2026-11-08 DeepL API から Ollama に変更
- DeepL API の無料枠が「毎月 50 万文字」から「1 回限りの 100 万文字」に変わり、使い切ると Growth プラン(月 ¥3,025〜、年払い)が必要になった。
- 無料プランの変更などの影響を避けるため、PC の中で動くローカル LLM(Ollama)に切り替えた。
- 画像をそのまま LLM に渡す方式も試したが、gemma3:12b では翻訳せずに英語のまま返したり内容を作り変えたりしたため採用しない。OCR で読み取った英文を翻訳する方式にした。
- 単語辞書とゲーム名を指示に入れると、ゲームの用語の誤訳(plant → 植物、extraction → エキザクトなど)がほぼ直ったため、設定に入れた。
- 言語は C# / WPF のまま(Windows OCR・クリップボード・配布との相性がよいため)。
- DeepL 版は main の 0df82cc。
