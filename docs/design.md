# 設計
- 対象: Windows 10 (2004以降) / Windows 11、まずwin-x64。
- 入力: クリップボード画像、画像ファイル、ドラッグ＆ドロップ。
- OCR: Windows.Media.Ocr、en-US、行単位で抽出。上限を超える画像は縮小。
- 翻訳: DeepL API、ENからJA。API Free/Pro切替。45秒タイムアウト。
- UI: 画像、編集可能な英文、日本語訳。処理中は並行実行を防止。
- 設定: APIキーとプランをDPAPI CurrentUserで保護。
- 履歴保存・ゲームへの介入・常時監視は初版の対象外。
- 将来: アプリ内範囲選択、単語辞書、翻訳履歴、ホットキー。
